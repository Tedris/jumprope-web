### DECISIONS (Ed, 2026-11-13)
- **DECISION — Chrome is moment-bound.** The no-panel rule is amended, not repealed: chrome may exist only in the `choose` and `pause` moments, token-bound (border `{colors.rope-lost}`, resting fill `{colors.ink}` @ 55%, selected fill `{colors.scrim}` @ 85%), and must never appear during play. Session 1's "no panels, no borders, no bold" absolutism is retired as contradicted by shipped code.
- **DECISION — New token, no new hues.** `bone-dim #b8b4a0` joins the table for card secondary copy. Panel fills and the hairline are NOT new tokens: they are alphas/re-uses of `{colors.ink}`, `{colors.scrim}` and `{colors.rope-lost}`, so every color token stays a plain hex (design.md spec rule). The palette is 13 token names over **10 distinct values** — `rope` aliases `bone`, `marker` aliases `role-sky`, `win` aliases `role-amber`, each because the same ink does two jobs (text vs. pip, accent vs. marker, accent vs. win line). No seventh hue, no fourteenth color.
- TOKEN NAMING — frontmatter colors moved to kebab-case (`role-sky`, `bone-dim`, `rope-lost`) to match both the design.md spec and the shipped CSS classes (`.role-sky`), and `name`/`description` were added; `typography`, `rounded`, `spacing` and `components` became structured objects so EXPERIENCE can reference `{typography.hud-primary.fontSize}` and resolve.
- **DECISION — HUD order is documented as-built** (six slots); no restructure story raised.
- **DECISION — Stamina reads fully diegetic** (posture, breathing, sore-walk, room wear; zero number, no new HUD slot) — FR47's zero-UI law extended to the day's central resource.
- **DECISION — Corner taps are the only non-gameplay gesture** (station switch, diary open, sleep, gate entry, shadow curation): no new keys, one verb preserved; accessibility carries on generous hit targets, not accelerators.
- v3 surfaces adopt UX-DR4–7 as written; diegetic-only, zero new panel classes, all prose via `content.js` selectors.
- Model Skins inherits UX-DR3 (five-palette legibility floor) + player-silent / author-loud failure; no player-facing UI surface is added by Epic 15.
- Open: win-copy divergence — v3 demotes the rope summit from run-win to an in-day beat, so `Summit. Altitude N` becomes an in-day line, not a run-over state `[ASSUMPTION: wording carries; the run-over state itself retires at Epic 12]`.
- Open: `aria-hidden` overlay vs diegetic v3 surfaces — a blind player can still read the room state on-screen but not via AT `[NOTE FOR UX: live-region pass if the audience widens]`.
- RETIRED — the Session 1 juice-tier assumption: `JUICE_TIERS` shipped in `js/shell.js:15-22` — skip 8/0.5/4, nearMiss 40/1.5/10, chargeUsed 50/1.6/11, ascend 60/1.75/12, ropeLost 65/1.9/14, win 0/1.95/15, trip 80/2/16. The spine's guessed ordering (`win > ascent > trip > nearMiss`) was wrong: **trip tops hitstop, and win carries zero hitstop by design** (freezing the run-ending tick would stutter the celebration). Shake/particles stay monotone.
- CORRECTED — the choose-state claim: `stopUntil` is a hitstop deadline set from the juice tiers (`shell.js:941`), not an offer freeze window; it gates sim stepping (`:902`) and the digit confirms (`:526`).
