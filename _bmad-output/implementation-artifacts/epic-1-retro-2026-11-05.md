## Challenges & growth areas

1. **Unfalsifiable test legs — the epic's #1 defect class** (4 of 5 stories): vacuous `scoreMul × 1` formula leg (1.1), streak-belt tautology (1.4), 0-vs-0 iFrames belt, shared-rope `deepEqual` tautology, `'NaN' in player` key-test (1.5). The data-URL `tickRun`-wrapper harness invites self-fulfilling legs. Countermeasure (action A3): every Epic 2 story adds the Task-4-style mutation check the 2.1 story already mandates.
2. **One real shipped bug** — pause/card-pick ate `CLOSE!` callouts at N≥2 (1.4): a Design-section claim ("the snap can only re-arm") was false in shipped code because `prevPhase` re-assigned before the wrap compare. Caught in review, fixed via shared `rearmCalloutGate`. Lesson: shell state-ordering claims in Design sections need a test leg, not a paragraph.
3. **Orphan deferrals echo.** The `ropeLost` event→cue wiring was confirmed silent in three consecutive reviews because no story owned the wiring itself. Deferrals with a named landing story get consumed; orphans don't. Fixed by assignment pass (action A1).
4. **Bookkeeping leaks repeated v1.0 Lesson 3:** future-dated `sprint-status.yaml`, File List omitting `sprint-status.yaml`, and 1.2's uncommitted residue entangling 1.3's clean-tree evidence (resolved by review decision D1). Countermeasure: story File Lists include tracking-file edits; status updates land the day of the work.
5. **Policy gap now closed:** AGENTS.md's byte-identical rule had no vocabulary for sanctioned re-contracts; reviews were adjudicating an unwritten exception.
