## Challenges & growth areas

1. **7.4's re-contract undercount is the epic's one real process miss.** The create round authorized 2 re-contracts; the dev round reddened SIX more frozen legs mid-round (locks (b) flip, balance enumeration input, locks (f) premise, ascent+winloss summit-copy prefixes, headless-sim/summitapproach view threading, balance dominated-deltas). The STOP-and-report → written-batch escalation worked exactly as designed — no frozen leg was freelazed, the tally was honest — but six unplanned reds in one story is a planning gap, not bad luck. Shared-shape changes (census keys, prompt-copy prefixes, harness call sites, deal twins) need enumerating BEFORE story creation, not discovering mid-round. → action A2.
2. **Green-but-dead witnesses concentrate on shared shapes.** Four found and fixed: 7.2's pause/tab-hide arms ran over a DEAD run (`enterPause` is running-gated) and a summit seed ending with `0===0` skips; 7.3's `mkCard` name===id let a `card.name` mutant hide (fixed by making name≠id ON PURPOSE); 7.4's `cadenceSim` kept a bare `startRun()` and silently APPLIED luckyecho mid-walk inside a green gate, and a reduced-motion A/B stayed vacuous while a mutant survived the full 602-leg suite. The lesson generalizes: where a leg reads through a harness default rather than the shipped path, green is cheap. Mutation probing is what makes green honest.
3. **Institutional memory worked; keep feeding it.** The feelcap AUD-02 trap (a literal `audio.js` token in a new COMMENT reddened a frozen leg) was paid once in 7.1's single red iteration, then pre-warned in every later story's pitfalls. 7.2's discovery that `winloss.test.js:196`'s permadeath census is green-by-construction AVOIDED an unnecessary re-contract — findings like these are worth their own ledger notes.
4. **Serial development is the accepted shape — for now.** Five stories ran strictly serially; ledger :291 (concurrent-story enablement) is ACCEPTED-PARKED with the enabling work named (split `shell.js` — 842 lines, touched by nearly every story; per-story ledger/census surfaces; symbol-anchored cites; dev-only `tsc --checkJs`). No pressure to change until an epic actually wants parallel writers.
5. **The v2 deploy has now waited through a whole epic.** Epic 6's A1 ("deploy cut, now") was not executed; Epic 7 shipped the Peel on top of undeployed v2 content. Shipped-but-unseen inventory: Epics 6's retuned balance, 7.x's meta layer, TRACK-1 music, the pause-menu audio config, the ghost-spread fix. Not a code problem — a disposition that keeps losing to the next epic's pull. → action A1, critical path this time.
