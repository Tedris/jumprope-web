    - Final pass: `OrthographicCamera(-1, 1, 1, -1, 0, 1)` + `PlaneGeometry(2, 2)` + `ShaderMaterial` (`depthTest: false, depthWrite: false`). Bayer matrix constant per Assumption A1.
    - Distance `Fog` matched to the dim sky `scene.background` (D-06, D-07 moody dusty blues/greens) — candidate values only; final values are settled by Task 2.
    - Precompile both scenes (`renderer.compile(scene, camera)` then `renderer.compile(postScene, postCamera)`) so the probe measures the look without a lazy-compile hitch (mirrors criterion 4; T-02-04).
    - One rAF loop advancing pivot rotation and the dither uniform `uInternalRes`; all per-stage code kept in port order (renderer → RT → materials+snap → post quad → loop) matching the `createScene` shape it will be ported into.
